# CommunityHub V3 Roadmap

## V3.0 — Identity
Rebuild the visual system, authenticated navigation, Command Center and FiveM in-game shell. Goal: CommunityHub immediately looks and behaves like a purpose-built operations product.

## V3.1 — People
Unified member profiles, staff lifecycle records, LOA, staff notes, promotions/transfers, evaluations and certification history.

## V3.2 — Flow
CommunityHub Flow workflow definitions, execution engine, application/training triggers, safe actions, execution history and UI.

## V3.3 — Operations
Integration Center, consolidated operational activity, audit review and improved incident/degraded-state visibility.

## V3.4 — Insights
Community activity, staff coverage, application/training trends, uptime and workflow impact based exclusively on real stored data.

## V3 release bar

V3 should not be marketed as complete solely because screens exist. A release milestone is complete when its underlying data path, permission checks, error/empty states, mobile/NUI behavior and regression tests are complete.
